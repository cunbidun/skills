# Personal skills

Personal agent skills and reusable workflows, copied from `~/.agents/skills`.
Each skill has its own directory containing `SKILL.md` and any supporting files.

| Skill | Purpose |
| --- | --- |
| `cleantests` | Review design smells and test value; simplify test suites. |
| `cr` | Review proposed changes in any review system with repository history in mind. |
| `distill` | Explain complex ideas using simple primitives and concrete causes. |
| `follow-data` | Follow data through writers, readers, storage, and caches. |
| `grill-me` | Stress-test plans and designs through consequential trade-offs. |
| `plan-executor` | Execute implementation plans and track completion. |
| `pr` | Finish repository work, run checks, and deliver pull requests. |
| `recall` | Retrieve earlier decisions and preferences from memory. |
| `reconsider` | Reassess assumptions and incorporate a different angle. |
| `remember` | Save durable lessons, decisions, and preferences. |
| `survey-merge` | Assess how to combine branches while preserving intent. |
| `trace` | Trace behavior through concrete actors, calls, and observed effects. |

These are independent file copies. Installed skill links and their Nix-managed
sources are unchanged. Bundled system and plugin skills are outside this collection.
